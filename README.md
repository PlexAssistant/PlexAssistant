# PlexAssistant

English | [正體中文](README.zh-TW.md)

Native `.strm` support for Plex: media info shows up, and items play.

## Quick start

Swap your Plex container image for `ghcr.io/plexassistant/plexassistant:latest`. See [`compose.yaml`](compose.yaml) for an example.
